## 1. 背景与目标

**背景**：需要一个轻量、结构完整的后台管理系统，用于练习并落地「登录鉴权 → 动态菜单 → 用户/角色管理 → 数据看板」全链路，且能真实部署。

**目标**

1. 提供基于 JWT 的登录鉴权与登录态保持；
2. 提供 RBAC：角色 → 菜单/按钮权限 → 前后端一致的权限表现；
3. 提供用户管理（增删改、启停、分页筛选）与角色管理（含菜单授权）；
4. 提供数据看板（概览指标、销售趋势、分类占比、分类排行）；
5. 商品管理、系统设置两个模块已补齐后端（`goods`、`settings` 表 + 10 个接口），不再是纯前端 Mock。

**成功指标**：核心 P0/P1 功能可用；接口自动化（Apifox 场景 35 步）全绿；页面加载 < 2s；无 P0/P1 缺陷。

## 2. 用户角色与权限

| 角色 | 账号 | 说明 | 可访问功能 |
| --- | --- | --- | --- |
| 超级管理员 | `admin / 123456` | 系统最高权限 | 全部菜单（13 条菜单/按钮权限） |

## 5. 功能详细说明

### F1 登录 `/login`

- **页面要素**：左侧暖色品牌面板（系统名 + 3 项指标）、右侧表单（账号、密码、记住我、登录按钮、演示账号提示）。
- **交互**
  1. 本地校验非空；提交中按钮 loading 且禁用；
  2. 成功 → 存 token + user → **再调 `GET /api/auth/me`** 取 `menus` / `permissions` → 跳 `/dashboard`；
  3. 失败 → 按 `message` 提示（`用户名或密码错误` / `账号已被禁用，请联系管理员`）；
  4. 未登录访问受保护路由 → 跳 `/login`；401 → 清 store 并跳登录。
- **验收**
  - [ ] 正确账号可登录并进入首页，刷新保持登录态；
  - [ ] 错误密码提示准确且不进入系统；
  - [ ] 禁用账号（status=0）登录被拒；
  - [ ] 退出登录后回到登录页，再访问受保护页被拦。

### F2 数据看板 `/dashboard`

- **页面要素**：页头（问候 + 区间切换 + 导出）、4 张 KPI（今日销售额/环比、今日销量、累计销售额、用户数）、销售趋势（双序列）、品类占比环形、排行 TOP5、快捷入口。
- **接口**：`overview` / `trend?days=30` / `category-ratio` / `rank?top=5`。
- **交互细节**
  - 环比为正绿、为负红；昨日为 0 时环比按 0 处理，不显示 `-100%`；
  - 图表随窗口缩放不变形（`resize`），销毁时 `dispose`；
  - 四个接口各自 loading / 错误 / 空态。
- **验收**
  - [ ] 四张 KPI 数值与接口一致，金额千分位两位小数；
  - [ ] 趋势图日期连续（后端补 0 的日期也画出来）；
  - [ ] 环形图按金额降序；排行条数 = `top`；
  - [ ] 断网/接口异常时展示错误态，不白屏。

### F3 销售统计 `/sales`

- **范围说明**：后端只有聚合接口，**没有明细分页接口**，本期只做「分类排行 + 占比 + 区间切换」。
- **验收**
  - [ ] 排行与占比数据来自 `rank` / `category-ratio`；
  - [ ] 页面不伪造"明细列表"或假接口。

### F4 用户管理 `/system/users`

- **列表**：账号（username + 昵称副行 + 头像）、角色标签、邮箱、状态开关、创建时间、操作。
- **筛选**：`keyword`（**仅 username/nickname**）、`role_id`、`status`；分页默认 10。
- **新增/编辑**：`username`、`password`、`role_id` 必填（新增）；编辑可改 `nickname`、`email`、`role_id`、`password`。
- **启停**：`PUT /:id/status`，数字 1/0；禁用自己会被后端拦。
- **删除**：二次确认；删除自己会被后端拦。
- **验收**
  - [ ] 列表分页、三个筛选单独与组合均生效，筛选后回到第 1 页；
  - [ ] 新增重复 username 提示「用户名已被占用」；
  - [ ] 启停后开关状态与库一致；
  - [ ] 禁用自己的按钮置灰并给出说明；
  - [ ] 删除有二次确认，删除后列表移除。

### F5 角色管理 `/system/roles`

- **列表**：角色名、code、描述、用户数（`user_count`）、操作。
- **新增**：`name`、`code` 必填，code 唯一。
- **编辑**：**必须同时提交 `name` 和 `description`**（只传 description 会把名称写坏）。
- **权限分配**：树形勾选（父节点勾选自动带子节点）→ `PUT /:id/menus` 全量覆盖；提供「清空权限」。
- **删除**：角色下有用户时禁止删除。
- **验收**
  - [ ] 勾选状态由 `GET /:id/menus` 数字数组回填；
  - [ ] 保存后重新登录，侧栏与按钮权限随之变化；
  - [ ] 清空权限后该角色 `me` 的 `menus` 为空；
  - [ ] 删除有用户角色提示「该角色下仍有用户，无法删除」。

### F6 商品管理 `/goods`（真实后端）

- **接口**：`GET /api/goods`（page/pageSize/keyword/category/status）、`GET /api/goods/categories`、`GET /api/goods/:id`、`POST`、`PUT`、`PUT /:id/status`、`DELETE`。
- **字段**：`name`、`sku`（唯一）、`category`、`price`、`stock`、`sales`、`status`(1/0)、`image`、`description`。
- **验收**
  - [ ] 列表/筛选/分页/空态与真实交互一致；
  - [ ] 新增、编辑、上下架、删除均有反馈与二次确认；
  - [ ] `price` 是字符串（"899.00"），展示前 `Number()`，不出现 `899.00` 变 `89900` 的千分位错误；
  - [ ] SKU 重复时展示后端文案「SKU 已存在」，库存为 0 与已下架两种状态分开展示。

### F7 个人中心 `/profile`

- **能力边界**：读 `GET /api/auth/me`；写 `PUT /api/users/:id`（`nickname` / `email` / `password`）。
- **明确没有**：`phone` 字段（`users` 表无该列）、头像上传接口（`avatar` 只能存外链）。
- **改密**：走同一个 `PUT` 带 `password`；成功后旧 token 仍有效 2h → 提示重新登录并主动登出。
- **验收**
  - [ ] 资料回显与保存正确；
  - [ ] 新密码 <6 位有提示；
  - [ ] 手机号区域按「待后端支持」置灰或移除，不假装可编辑。

### F8 系统设置 `/settings`（真实后端）

- **字段**：`systemName`、`slogan`、`notice`、`themeColor`、`siderCollapsed`。
- **接口**：`GET /api/settings`（读）、`PUT /api/settings`（部分保存，回传完整对象）、`POST /api/settings/reset`（恢复默认）。
- **实现**：保存后把 `themeColor` 写入 `ConfigProvider` token；`siderCollapsed` 建议仍存本地（用户级偏好）。
- **验收**
  - [ ] 保存后刷新仍生效（数据来自后端，不再是本地假象）；
  - [ ] `systemName` 为空 / `themeColor` 非 `#RRGGBB` 时展示后端文案；
  - [ ] 「恢复默认」有二次确认，恢复后界面即时回退。

## 6. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 首屏 < 2s；列表接口 < 500ms（千级数据） |
| 兼容性 | Chrome / Edge 最新版；分辨率 ≥ 1366×768（设计基准 1440×900） |
| 安全 | 密码 bcrypt 存储、JWT 2h 过期、`.env` 不入库；错误信息不泄露堆栈 |
| 可用性 | loading / 成功 / 失败 / 空态四态齐全；删除与危险操作二次确认 |
| 可维护性 | 前后端分层、统一响应 `{code,message,data}`、请求走统一 api 层 |
| 一致性 | 视觉遵循 `02_UI设计规范.md`（暖色 v2.0），不擅自新增品牌色 |

## 7. 数据字典（与真实表一致）

**roles**：`id`、`name`（角色名）、`code`（唯一标识）、`description`、`created_at`、`updated_at`

**users（后台账号，非会员）**：`id`、`username`（唯一登录名）、`password`（bcrypt）、`nickname`、`email`、`avatar`、`role_id`、`status`（1 启用 / 0 禁用）、`created_at`、`updated_at`
> **没有 `phone` 字段**。

**menus**：`id`、`parent_id`、`name`、`path`、`icon`、`type`（1 菜单 / 2 按钮）、`permission`、`sort`

**role_menu**：`role_id` + `menu_id`（联合主键，级联删除）

**categories**：`id`、`name`、`sort`

**sales**：`id`、`category_id`、`amount`、`qty`、`sale_date`

**goods**：`id`、`name`、`sku`(UNIQUE)、`category`、`price` DECIMAL(10,2)、`stock`、`sales`、`status`(1/0)、`image`、`description`、`created_at`、`updated_at`

**settings**：`key`（主键：systemName/slogan/notice/themeColor/siderCollapsed）、`value` TEXT、`updated_at`（键值表，接口层合并默认值返回扁平对象）
