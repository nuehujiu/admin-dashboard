## 1. 设计原则

1. **清晰优先**：层级靠字号/留白/分隔线区分，不靠彩色卡片。
2. **克制专业**：全站只有一个强调色（橙），橙只出现在「可点击 / 需注意 / 关键数字」。
3. **一屏完整**：1440×900 内页头、筛选、表格或图表、分页全部可见，不留半截。
4. **反馈明确**：loading / 成功 / 失败 / 空态四态齐全，危险操作二次确认。

## 3. 字体与字号

字体族：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
数字统一 `font-variant-numeric: tabular-nums`，表格与 KPI 数值对齐不跳。

| 层级 | 字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | 21px | 650 | 页头 H1 |
| KPI 数值 | 26px | 650 | 卡片主数字 |
| 卡片标题 | 15px（密集区 14.5px） | 600 | 区块标题 |
| 正文 / 表格 | 13.5px | 400 | — |
| 辅助说明 | 12–12.5px | 400 | 表头、时间戳、说明 |
| 标签 / 坐标轴 | 11.5–12px | 400–500 | — |

---

## 4. 间距 / 栅格

- 基数 **4px**，常用 8 / 12 / 14 / 16 / 18 / 22。
- 内容区 padding：`20px 28px 22px`；卡片内 padding：`16–22px`；卡片间距：`16px`。
- 1440 宽下侧栏 216px，内容区约 1224px；KPI 四列等宽，间距 16px；图表区左 1.62fr / 右 1fr。
- 表格列间距靠 padding 14px 实现，不使用竖线。

## 5. 圆角 / 阴影 / 描边

| 元素 | 圆角 | 阴影 |
| --- | --- | --- |
| 卡片 | 14px | `0 1px 2px rgba(28,25,23,.04)` |
| 按钮 / 输入框 / 下拉 | 8px | 主按钮 `0 1px 2px rgba(244,97,29,.25)` |
| 标签 Tag | 6px | 无 |
| 商品缩略图 | 9px | 无 |
| 浮层 / 下拉菜单 | 10–12px | `0 2px 4px rgba(28,25,23,.04), 0 12px 28px rgba(28,25,23,.05)` |
| 头像 | 圆形 | 无 |

描边统一 1px；**禁止**用彩色描边代替状态标签。

## 6. 布局

```
┌────────────┬──────────────────────────────────────────────────┐
│ Sider 216  │ Header 64px：面包屑 · 搜索 · 通知 · 用户菜单      │
│ 白底       ├──────────────────────────────────────────────────┤
│ 右侧 1px 线│ Content                                          │
│ 分组导航   │  页头：标题 + 说明          [区间切换] [主按钮]    │
│            │  ┌ 筛选栏 ────────────────────────────────────┐   │
│            │  │ 表格 / 图表 / 表单卡                        │   │
│            │  └────────────────────────────────────────────┘   │
└────────────┴──────────────────────────────────────────────────┘
```

- **侧栏为浅色**（`#FFFFFF`，右侧 1px `#EDE8E2`），不再使用深蓝底。
- 导航分 4 组：概览（数据看板/销售统计）、运营（商品/用户）、系统（角色/设置）、账户（个人中心）；组标题 11px `#BDB6AE`。
- 选中项：`#FFF2EA` 底 + `#B9400A` 文字 + 600 字重，**不加左侧竖条**。
- 顶栏：左侧面包屑（12.5px 弱色），右侧搜索/通知/用户（头像 32px + 名称 13px + 角色 11px，左侧 1px 分隔）。

## 7. 组件规范

| 组件 | 规格 |
| --- | --- |
| 主按钮 | 高 34px（登录页 44px），主色填充 + 白字 13px/500，圆角 8px，带 6px 图标间距 |
| 次按钮 | 白底 + 1px `#EDE8E2`，hover 底 `#FBFAF8` |
| 文字按钮 | 无边框；hover `#FFF2EA` + 主色墨 |
| 行内操作 | 高亮主色墨，删除用危险色，分隔符 `·` 弱色；**必须 nowrap**，操作列固定宽 176px |
| 输入框 | 高 34px（表单区 36px、登录页 42px）；聚焦 `#F9A87E` 描边 + `0 0 0 3px rgba(245,97,29,.10)` 光晕；左侧可放 16px 图标 |
| 下拉选择 | 与输入框同高，右侧 14px 箭头，`min-width` 116px |
| 表格 | 表头 44px、`#FBFAF8` 底、12px `#8E8881` 字、无竖线；行高 54–70px 随页高自适应；首列 padding-left 20px |
| 状态标签 | 高 24px，圆角 6px，左 5px 圆点；上架/启用=绿、下架/禁用=灰、未开启=橙黄 |
| 角色标签 | 超级管理员=橙底、运营=青底、成员=灰底 |
| 开关 | 36×20，开=Success、关=`#DDD7CF`；仅用于状态列 |
| 分页 | 30×30 圆角 8，当前页主色填充；右侧带「N 条 / 页」下拉；展示「共 N 条 · 第 x / y 页」 |
| 复选框 | 16×16 圆角 4；选中主色填充 + 白色对勾 |
| 卡片 | 白底 + 1px 线 + 14px 圆角；标题区 padding `16px 20px 0`，含副标题时副标题 12px 弱色 |

| 图表卡 | 标题 + 副标题 + 图例在右上；图表区留 padding 8–20px；折线 2.2px、面积 14% 透明、第二序列虚线 |

| 加载态 | 表格骨架/遮罩；提交按钮 loading 且禁用 |
| 弹窗 | 圆角 12px，标题 15px/600，底部右对齐「取消 + 确定」，删除用危险色按钮 |

## 9. 交付与落地

- **源文件优先**：样式以 `UI预览.html` 为准，颜色/间距/字号可直接从 CSS 变量取，不要凭截图目测。
- **变量化**：前端把第 2–5 章的 token 写进 `styles/tokens.css`，antd 用 `ConfigProvider.theme.token` 映射（见 `开发文档.md` 第 9.7 节）。
- **切图**：图标统一 SVG（1.6px 描边、24 网格）；商品缩略图位图导出 @2x，命名 `模块_元素_状态`。
- **验收**：对照 PNG 检查主色、圆角、表头、行高、操作列是否换行；交互态检查 hover / focus / disabled / loading。
- **禁止**：擅自新增品牌色；用彩色块代替标签圆点；表格加竖线；主按钮以下出现第二个同强度按钮。
- **商品 / 设置（2026-11-10 起有后端）**：两页数据均来自真实接口，**不要再加「示例数据 / 本地生效」提示**；`/profile` 的手机号、头像上传仍按「待后端支持」置灰。
- **权限联动**：侧栏菜单由 `/api/auth/me` 的 `menus` 生成，`operator` 只能看到「数据看板」「销售统计」两项，设计稿的完整侧栏是 `admin` 视角。
